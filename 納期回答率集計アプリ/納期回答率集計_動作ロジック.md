# 納期回答率集計アプリ 動作ロジック

作成日: 2026-11-12 · 対象: 納期回答率集計.html

## 概要

注残リストの各行について「納期回答日が入っているか」を数え、集計区分ごと・工場ごとに納期回答率を出すアプリです。納期回答率は次の式で計算します。

> 納期回答率 ＝ 納期回答件数 ÷ 注残件数

アプリは HTML ファイル1つで、ブラウザ（Edge / Chrome）で開いて使います。ファイルはブラウザの中だけで処理し、外部へ送りません。元の注残リストも書き換えません。ただし、Excel の読み書きに使う部品（SheetJS、ExcelJS）を開くたびにインターネットから読み込むので、ネット接続が必要です。

## 処理の流れ

1. 注残リストを読み込み、見出し行と集計するデータの範囲を決める
2. ユーザ欄１から、各行の工場コード（F / H / J）を決める
3. ユーザ欄１が空白の行は、手修正またはリストで工場コードを補う
4. 納入指示日の範囲を指定していれば、範囲外の行を外す
5. 集計区分ごとに条件で行を絞り込む
6. 工場別・セグメント別に、注残件数と納期回答件数を数える
7. 画面に表示し、必要なら Excel に出力する

日付の範囲・リスト・手修正を変えると、そのたびに 2〜7 をやり直します。

## 1. 読み込み

### 見出し行とデータ範囲

- **見出し行:** 上から30行目までを探し、「納期回答日」と「ユーザ欄１」の両方がある最初の行を見出し行にします。
- **データ範囲:** 見出しの次の行から、すべての列が空の最初の行の手前までです。表の下に別の集計表などがあっても、空の行で区切られていれば集計に入りません。
- **シート:** 見出し行が見つかった最初のシートを自動で選びます。画面の「対象シート」で変更できます。

### 使う列

列は見出しの名前で探すので、列の位置が変わっても動きます。見出しの比較では、全角と半角、スペースの有無を区別しません。

| 列 | 必須 | 使い道 |
| --- | --- | --- |
| 事業所名 | ○ | 「富士宮」の判定 |
| セグメント | ○ | カテゴリ別の集計 |
| 納期回答日 | ○ | 回答あり・なしの判定 |
| 納入指示区分 | ○ | JIT の判定 |
| ユーザ欄１ | ○ | 工場コード |
| 納入指示日 | | 日付の範囲指定 |
| 品番 | | 空白埋め用リスト・除外品番リストとの照合 |
| 納入指示番号 | | 空白埋め用リストとの照合（補助） |
| 納入場所、取引先名 | | 空白行の確認画面に表示するだけ |

必須の列が見つからないときは、足りない列名を表示して集計しません。

### 文字の扱い

値を比べるときは、次のようにそろえてから判定します（元のデータは変えません）。

- 全角の英数字・記号は半角にする（例: 「ＪＩＴ」→「JIT」、「Ｊ」→「J」）
- 前後のスペースを取り、続いたスペースは1つにする
- 工場コードと品番の照合では、大文字と小文字を区別せず、スペースも無視する

## 2. 工場コードの決め方

ユーザ欄１の値から、次の順で工場コードを決めます。

| ユーザ欄１の値 | 工場コード | 例 |
| --- | --- | --- |
| 空白 | (空白) → 「3. 空白の補完」へ | |
| 「FJ」で始まる | J | FJ |
| 「J」で始まる | J | J、j、Ｊ、J 4267000 1F、J 資材 2F |
| それ以外 | 値そのもの（大文字） | F、Ｆ → F、H |

工場名は F＝本社工場、H＝厚木事業所、J＝南陵工場です。表の並び順は F、H、J、その他（名前順）です。

## 3. ユーザ欄１が空白の行の補完

空白の行は、次の優先順で工場コードを決めます。

1. **手修正:** 確認画面で選んだ工場コード
2. **工場区分空白埋め用リスト:** 「リストで埋める」にチェックがあり、リストに品番があれば、そのコード
3. **どちらも無い:** 工場「(空白)」として集計する

### 工場区分空白埋め用リスト

- **読み込み:** 見出しに「ユーザ欄１」と「品番」がある最初のシートを使います。ユーザ欄１が空白の行は読み飛ばします。リストのユーザ欄１にも「2. 工場コードの決め方」を当てはめるので、FJ や J 1F は J になります。
- **照合のキー:** 品番です。品番が一致すれば、納入指示番号が違っても、そのコードを入れます。
- **同じ品番に複数のコードがあるとき:** 納入指示番号も一致する行のコードを使います。それも無ければ埋めずに、手修正に回します。リストの欄に、その品番を一覧で表示します。
- **保存:** 一度読み込むとブラウザに保存され、次回も使えます。「登録解除」で消せます。

### 確認画面（手修正）

- **開くとき:** リストで埋まらなかった空白行がある場合、集計のあとに自動で開きます。一度見た行では、再集計しても自動では開きません。画面の「空白行を確認・修正」から開き直せます。
- **選び方:** 各行の工場を F / H / J から選んで「修正して再集計」を押します。「未設定の行をまとめて」で、未設定の行を一度に同じ工場にできます。
- **対象の行:** 確認画面に出るのは、日付の範囲に入っている空白行だけです。
- **リセット:** 手修正は、別のファイルを開くか、シートを切り替えると消えます。日付を変えても消えません。

## 4. 納入指示日の範囲

- **指定のしかた:** 「20261204」「2026/12/04」のように入力するか、📅 ボタンのカレンダーで選びます。
- **範囲:** 指定した日を含み、それ以前の行が対象です（納入指示日 ≦ 指定日）。
- **納入指示日が空の行:** 日付を指定したときは対象外になります。
- **指定しないとき:** 空欄なら全件を集計します。
- **日付の形式:** Excel の日付（シリアル値）と、文字の日付（2026-12-04、2026/12/04、2026年12月4日 など）のどちらでも読めます。

## 5. 判定のルール

| 判定 | ルール |
| --- | --- |
| 回答あり | 納期回答日が空でなければ「回答あり」。中身が日付かどうかは見ない |
| 富士宮 | 事業所名が「富士宮」と完全に一致する |
| JIT | 納入指示区分の先頭の「番号:」を取った残りが「JIT」と完全に一致する。「1:ＪＩＴ」は JIT、「6:手配ＪＩＴ」は JIT ではない |
| セグメント | セグメントの値ごとに数える。空の行は「(空白)」 |

## 6. 集計区分

日付の範囲と空白の補完を済ませた行から、集計区分ごとに次の条件で絞り込みます。

| 集計区分 | 条件 | 表の形 |
| --- | --- | --- |
| 1. 工場別 | 全件 | 工場別 |
| 2. 工場別 × カテゴリ別 | 1 と同じ行 | 工場ごとのセグメント別 |
| 3. 富士宮のみ | 事業所名＝富士宮 | 工場別＋セグメント別の内訳 |
| 4. 富士宮のみ・JIT除く | 3 から JIT を除く（手配JITは残す） | 工場別＋セグメント別の内訳 |
| 5. 富士宮のみ・JIT除く・南陵工場・除外品番を除く | 4 のうち工場が J の行から、除外品番リストの品番を除く | 南陵工場のみ＋セグメント別の内訳 |
| 参考. JIT除く（全事業所） | 全件から JIT を除く（手配JITは残す） | 工場別＋セグメント別の内訳 |

集計5は、除外品番リストを登録したときだけ表示します。

### 除外品番リスト（集計5）

- **読み込み:** 見出しに「品番」があるシートをすべて読みます（例: 指示区分変更依頼追記分(20260911)土岐含む.xlsx）。
- **使うシート:** 画面の「使うシート」で選んだ1枚の品番だけを使います。最初は「納期回答対象外」シートです。そのシートが無いときは、品番のある最初のシートになります。
- **照合:** 品番が一致する行を除きます。全角と半角、大文字と小文字、スペースは区別しません。
- **保存:** 一度読み込むとブラウザに保存されます。シートの選択も保存されます。

### 数え方

- **注残件数:** 条件に合う行の数です。数量・指示数は使わず、1行を1件と数えます。
- **納期回答件数:** そのうち「回答あり」の行の数です。
- **総計:** 工場ごとの件数の合計です。工場「(空白)」の行も総計に入ります。

## 7. 画面の表示

- **カード:** 上部に、集計区分ごとの総計の回答率と件数を並べます（2 は 1 と同じなので出しません）。
- **表:** 集計区分ごとに工場別の表を出します。3 以降は「セグメント別の内訳を表示」を開くと内訳が見られます。
- **チェック用:** 画面下の「チェック用」を開くと、ユーザ欄１の元の値がどの工場コードになったか、納入指示区分のどの値を JIT と判定したかを件数つきで確認できます。

## 8. Excel 出力

「集計結果をExcel出力」で、次のシートを持つファイル「納期回答率集計_（元ファイル名）.xlsx」を作ります。

| シート | 内容 |
| --- | --- |
| サマリー | 集計区分（1・3・4・5・参考）× 工場の注残件数・回答件数・回答率と総計 |
| 南陵工場まとめ | 南陵工場（J）だけを集計区分ごとに並べた表と、セグメント × 集計区分の表。セグメント表の総計行で 4 と 5 は赤字・太字 |
| 1 工場別 ～ 参考 JIT除く | 集計区分ごとの工場別の表とセグメント別の表 |
| 明細1 全件、明細3、明細4、明細5、明細 参考 | 集計区分ごとに、集計に入れた行。左に「Excel行・集計用工場・納期回答・工場の補完」、右に注残リストの元の列。未回答は赤で表示 |
| ユーザ欄1空白行 | 空白だった行と、補完後の工場・補完元。空白のまま残った行は黄色 |

- **シートごとの見出し:** 各シートの上に、元ファイル名・シート名・納入指示日の範囲・作成日時を入れます。
- **明細の日付:** 見出しが「〜日」の列で Excel の日付になっているものは、「2026-12-04」の形の文字で出します。
- **予備の出力:** ExcelJS を読み込めないときは、書式なしの形式（集計表1枚＋明細＋空白行）で出力します。

## 9. ブラウザに保存するもの

| 保存するもの | 保存名 |
| --- | --- |
| 工場区分空白埋め用リスト | nouki-kaitou.fillList.v1 |
| 除外品番リスト（全シートの品番と、選んだシート） | nouki-kaitou.excludeParts.v1 |

保存先はブラウザ（localStorage）なので、別のPCや別のブラウザには引き継がれません。手修正の内容と日付は保存しません。

- **空白埋め:** 空白埋め用リスト（修正版）を使用。空白44件をすべてリストで補完
- **除外品番:** 「納期回答対象外」シートを使用
